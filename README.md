# 🌐 Naveenkumar B — Portfolio

A modern, responsive personal portfolio website built with **HTML5**, **CSS3**, and **JavaScript (ES6+)**. Showcasing skills, full-stack projects, education, certifications, and contact information for **Naveenkumar B**, an aspiring Java Backend Developer and M.Sc. Computer Science graduate.

---

## ✨ Features

- 🎨 **Dark / Light Theme** — Toggle between an elegant charcoal dark mode and clean ivory light mode
- ⌨️ **Typing Animation** — Dynamic hero section with rotating roles (Java Backend Developer, Spring Boot Specialist, Full Stack Developer, RESTful API Engineer)
- 📱 **Fully Responsive** — Fluid typography and adaptive layouts optimized for mobile, tablet, and desktop
- 🧭 **Smooth Navigation** — Scroll spy, smooth anchor scrolling, and smart auto-hiding navbar
- 📂 **Project Accordion** — Expandable project cards with architectural breakdown, features list, and GitHub links
- 🔍 **Category Filter** — Instant filtering by All Projects, Java / Backend, and Full Stack / React
- 🎞️ **Scroll Animations** — IntersectionObserver-powered staggered fade-up effects
- 📋 **Copy Email Action** — One-click email copying with custom animated toast feedback
- 📄 **Resume Download** — Direct download access for PDF and DOCX resume formats
- ⬆️ **Back to Top** — Floating smooth-scroll return button

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Naveenk198/Portfolio.git
   cd Portfolio
   ```

2. **Open in browser**
   - Simply double-click `index.html` to view in any modern web browser
   - Or start a local development server:
     ```bash
     python -m http.server 8000
     ```
     Then open `http://localhost:8000`
